# JavDB Client for Scripting

一个面向 Scripting 的 JavDB 公开资料查询与本地收藏管理客户端原型。

## 当前功能

- A 风格视觉：酒红色强调色、卡片式布局
- C 结构：首页 / 搜索 / 收藏 / 我的
- 通过番号、影片名或女优关键词搜索 JavDB 公开页面
- 展示番号、标题、封面、评分、评分人数、发行日期和标签
- 查看影片资料原页面
- 影片详情页原型
- 本地收藏、想看、看过入口原型
- 女优关联入口
- 个人备注入口
- JSON 导入/导出入口
- 隐私说明和缓存管理入口

## 运行方式

将本目录放入 Scripting 的 scripts 目录，在 Scripting 中运行 `script.json` 对应项目。

## 数据来源和限制

本项目只请求 JavDB 的公开搜索页面，不保存 JavDB 密码，也不实现自动登录或云端同步。
JavDB 页面结构、年龄确认、网络策略或服务条款变化都可能影响搜索功能。
如遇到年龄确认或反爬页面，请先在浏览器中完成站点要求，并遵守当地法律、版权和网站服务条款。

本项目不包含破解、DRM 绕过、付费内容获取或批量下载逻辑。
