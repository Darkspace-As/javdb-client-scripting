# JavDB Client for Scripting

一个面向 Scripting 的 JavDB 公开资料查询与本地收藏管理客户端。

## 当前功能

- A 风格视觉：酒红色强调色、卡片式布局
- C 结构：首页 / 搜索 / 收藏 / 我的
- 首页加载 JavDB 公开影片列表
- 通过番号、影片名或女优关键词搜索 JavDB 公开页面
- 展示番号、标题、封面、评分、评分人数、发行日期和标签
- 加载失败时显示错误与重试按钮
- 查看影片资料原页面
- 真实影片详情字段：片长、片商、女优、标签、详情评分
- 收藏、想看、看过和个人备注会保存到 Scripting 本地 Storage
- 自动记录最近浏览过的影片- 女优关联入口
- 个人备注入口
- JSON 导入/导出入口
- 隐私说明和缓存管理入口

## 运行方式

将本目录放入 Scripting 的 scripts 目录，在 Scripting 中运行 `script.json` 对应项目。

## 数据来源和限制

本项目请求 JavDB 的公开首页和公开搜索页面，不保存 JavDB 密码，也不实现自动登录或云端同步。
JavDB 页面结构、年龄确认、网络策略或服务条款变化都可能影响功能。
如果手机端显示年龄确认或访问限制，请先在浏览器中完成站点要求，并遵守当地法律、版权和网站服务条款。

本项目不包含破解、DRM 绕过、付费内容获取或批量下载逻辑。

## 开发状态

当前为早期版本：首页、搜索和影片详情已接入真实公开页面解析；收藏、想看、看过、备注和浏览记录已接入本地 Storage。账号登录、云端同步、女优独立收藏和 JSON 文件导入导出仍在继续完善。
